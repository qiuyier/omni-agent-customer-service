# v1.0.0 — 通用文本客服源码发布

发布日期：2026-10-28。版本以 GitHub 的 v1.0.0 标签及 Release 为准；本文描述该版本的范围，不是公网生产开放批准。

## 交付能力

- WebChat 客户聊天、坐席工作台，以及申请人工、接管、回复、结束、新咨询闭环。
- PostgreSQL 消息/会话持久化、回执和历史恢复；提供迁移、配置和资源预检。
- 通用业务身份适配契约与 Node host-kit；CRMEB 仅为示例，不是运行依赖。没有原客服模块的系统也可接入，但须提供可信登录与员工授权。
- 单业务独立实例可显式启用 AI 和 keyword FAQ；默认 fake，模型失败不降级成假回复。
- 本机参考部署、已构建网页、源码及锁定依赖。自有代码 MIT，第三方许可保留于 LICENSE、third_party 与页面 LEGAL 文件。

## 从哪里开始

先读 [最小使用指南](minimal-use.md)，再按 [参考部署](../deploy/reference/README.md)初始化私密配置、构建、启动独立 PostgreSQL、迁移、预检和启动。不要复用业务原库或把演示认证暴露到公网。

Release 附件提供从标签目标提交生成的源码 tar.gz、逐文件 SHA-256 清单和验证摘要；SHA256SUMS 校验附件。GitHub 自动生成的 Source code 也是同一标签源码，但压缩格式/哈希不必与自制附件一致。没有打包 Go 运行时、node_modules、数据库或本机凭据。

## 验证与限制

- 本机 macOS 已完成核心浏览器闭环、独立 PostgreSQL 安装及实际重启历史比较。发布前对最终源码再运行 Go test/vet/build、依赖校验、默认恢复与离线接入测试，结果随 Release 提供。
- 公开仓库首次默认恢复 CI 已通过：[运行 40689188200](https://github.com/qiuyier/omni-agent-customer-service/actions/runs/40689188200)。这是 Ubuntu/Node 24 的自动恢复检查，不等于 Linux 完整部署或云端数据库验收；最终提交 CI 结果见仓库 Actions。
- 模块声明 Go 1.25.0；本机发布验证使用 Go 1.27.0、Node 26.7.0。参考部署要求及 CI 配置见各自文档，不把单次测试等同于所有最低版本兼容保证。
- 本轮不调用真实模型。历史 AI 小样本只证明相应实例/题目的接线，不保证任意模型、资料或准确率。
- 多业务共享实例仅承诺 fake/人工，AI/知识隔离使用独立实例。没有订单、退款、预约等业务执行工具。
- 早期 /v1 API、语义检索、依据校验及多意图实验不因存在于源码就成为此版本默认推荐链路。
- 生产接入须另行验证真实身份/授权、HTTPS、最小权限、密钥、备份恢复及值守；本机演示认证不是生产 IAM。

## 公开历史与证据

公开 Git 历史保留原有 145 个开发提交的顺序与父子关系，移除历史私密配置、截图/原始验收材料并匿名化个人邮箱和路径。因此提交 SHA 已变化；旧报告的 commit/hash 是原历史记录，不作为本次发布包校验和。历史材料引用已明确标为私密备份；不要用已删原始输入复跑归档实验。

测试所需最小虚构夹具已独立保留。公开扫描覆盖已知私密值、配置路径及历史对象，但不承诺发现所有未知敏感内容。后续贡献请使用 noreply 邮箱并禁止提交真实凭据。
