# 1.0.0 发布后优化录

建立日期：2026-10-24。维护状态：持续记录，正式发布 1.0.0 后再逐项评估和安排。

## 当前工作原则

按用户决定，当前优先把通用客服系统的核心流程端到端跑通，不继续围绕非阻断优化反复扩展验收。CRMEB 是接入验证对象，不把系统做成电商专用客服。

- 后续发现的非阻断优化统一记录在本文，避免散落在聊天或多份待办中。
- 每项记录现状、改进价值、延后原因、完成标准和状态；重复问题更新原条目。
- 记录不等于安排实施，1.0.0 发布后再评估优先级；不自动执行推送、发布或外部系统变更。
- 核心流程无法使用、身份串号、数据泄露/丢失等问题不是可延后的优化，仍需作为发布前阻断问题处理。必要回归继续运行，不能把“暂缓优化”理解为跳过基本验证。
- 新一轮工作先检查是否直接有助于系统核心流程跑通；若只是非阻断完善，先记入本表，不自动启动新一轮开发。
