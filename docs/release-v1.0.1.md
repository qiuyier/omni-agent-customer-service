## 本次更新

### 网络异常不再一律提示登录失效

共享业务身份边界区分核验中、离线、身份服务暂不可用，以及已确认登录失效/无权限。离线或服务异常时隐藏消息，并允许重新核对；联网事件重新触发身份检查。仅身份核验成功后恢复显示，联网本身不代表已认证。

切号、退出、旧请求结果拒绝等安全边界保留。网络恢复不会自动重发客户消息；退出未确认时也不会因联网事件重新展示身份内容。

适用于 business-login、office-portal 和 fresh-onboarding 共用的 HostSessionBoundary。CRMEB 自有认证页面未改用此边界，不将该提示修正扩展声称覆盖全部接入方。

### 参考页面说明更准确

统一使用“参考业务”，不再把部署账号称作临时账号。业务认证库、客服消息存储与回复模式分别说明；存储/回复能力仍由明确的服务端元数据决定，不把未知模式标成 AI 或模拟回复。

业务登录用户不再被引导“选择演示账号”，共享说明不假设接入方一定使用密码认证；坐席工作台不再假设业务系统原本已有客服模块。保留参考/演示性质，不宣称完整白标或生产 IAM。

### 云端回归验收补齐

默认回归、隔离 PostgreSQL 回归通过；故意失败的临时测试正确标红，报告仍可下载，临时数据库及远端分支已清理。详见 [云端验收](recovery-ci-acceptance-2026-10-29.md)。

## 从 1.0.0 更新

- 本次无数据库 schema、Go 依赖及后端 API 契约变更，不新增迁移或要求清空数据。
- 更新到正式发布后确认的 1.0.1 版本，按 [参考部署说明](../deploy/reference/README.md)重新构建并重启应用，使嵌入或静态前端资源生效。独立托管页面需同步对应构建产物及 LEGAL 文件；不要只改源码而继续分发旧 app.js。
- 保留现有私密配置、账号和数据库卷，勿用示例配置覆盖；自定义页面请审阅差异后合并。
- 更新后检查客户与坐席登录、页面导航、身份核验提示和已有消息读取。生产实例应在维护窗口操作，并先按自身备份策略保留可恢复状态。
- 如需回退，恢复原 1.0.0 应用与页面产物，保留原私密配置及数据库；本补丁没有需要逆向执行的迁移。回退仍需目标环境验收，不以删除数据库作为恢复手段。

## 证据与限制

- [身份提示专项](network-identity-status-2026-10-29.md)：实际组件的浏览器故障注入，不是断开操作系统网络或全量生产认证测试。
- [参考文案检查](reference-copy-2026-10-29.md)：客户/员工登录页浏览器导航和文案组合测试。
- [云端回归](recovery-ci-acceptance-2026-10-29.md)：网页/宿主 127 项、网关 10 个 Go pass 事件、数据库 12 个 Go pass 事件；Go 计数包含父子测试及重复执行。
- PostgreSQL 回归包含 HTTP 网关/连接池重建，不等同于数据库容器宕机恢复。本补丁未重跑全新安装、真实浏览器完整持久化闭环或实际数据库重启。
- 没有真实模型调用，不新增知识管理、业务执行工具或多租户 AI 能力；1.0.0 的支持范围和生产部署前提继续有效。
- GitHub Actions 运行时弃用提示作为 OPT-004 跟踪，本次未升级相关 Actions。
