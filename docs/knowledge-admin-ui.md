## 使用与构建

按 [管理员配置](knowledge-admin.md) 启动 `knowledge-admin` 后访问其配置 Origin 的 `/`。
登录使用独立管理员账号，不是普通用户或坐席。没有默认生产账号。

前端使用已有 React / Tailwind 依赖，没有新增 npm 包：

```sh
cd web/chat
npm ci
node build-admin.mjs
```

生成 `internal/knowledge/adminui/assets`，然后从仓库根目录 `go build ./cmd/knowledge-admin`。
Go 二进制内嵌管理专用 HTML、JS、CSS 与第三方许可文件。不改客户/坐席构建产物。
资源仅允许固定路由、GET/HEAD，设置 no-store、nosniff、禁止嵌框与仅同源资源的 CSP。

## 操作顺序

1. 登录后新增 FAQ，填写唯一 ID、标题、答案、资料来源和逐行关键词。
2. 保存草稿：只保存编辑，不影响检索；所有字段和大小仍由服务端严格校验。
3. 拥有 publish 权限的管理员确认发布。未保存编辑时禁止发布/回退，避免误认为本地修改已上线。
4. 可选择历史版本回退；回退不替换草稿。空版本还需单独勾选确认。
5. 右侧显示当前发布 hash、草稿 hash 与最近 20 条成功操作。

只读账号不可编辑，编辑账号不能发布；前端按钮不是授权边界，服务端继续逐次检查权限。
当前页面不提供批量导入、搜索、大规模分页、历史版本内容预览或自动合并。

## 冲突、断网与身份

- 409 revision_conflict：保留本地编辑并暂停写入，不自动更新 revision 重试。
- 写请求发生网络异常、无法解析成功响应、5xx 或 outcome_unknown：保守认定结果可能已落库，暂停写入。
- “核对服务器状态”只读，不重发。可以展开服务器草稿 JSON、核对 revision/当前发布/操作记录。只有用户明确放弃本地编辑、采用服务器草稿后，才恢复操作。
- 请求 15 秒超时，期间禁止重复点击；没有自动写重试。
- 每次写前和读取结果后核对 `/auth/me`。管理请求携带非凭据 `X-Knowledge-Session`，服务端拒绝与 Cookie 会话版本不符的请求，避免跨标签切号后以另一身份写入或退出另一会话。旧 API 客户端可不传该可选头。
- 每 30 秒与窗口恢复焦点时核对身份；过期、切号、403 或无法确认身份时清空页面数据。隐藏页面遮住内容，恢复后重新检查。退出即清空本地，退出请求失败会明确提示服务端会话未确认撤销。
- 不把密码、会话 token 或 FAQ 放入 localStorage/sessionStorage。未保存内容仅在内存中；失效、刷新、离开页面会丢失，离开前有未保存提醒。

## FAQ 本地搜索

草稿工作区支持按标题、答案内容、单个关键词做子串搜索，忽略大小写和搜索词首尾空白；不搜索 ID 或资料来源，不使用模型或语义检索。显示匹配数和总数，可清除搜索。

## JSON 草稿导入、导出

管理页提供已保存草稿导出和示例模板下载，文件为 FAQ 对象数组（id/title/content/source/keywords），不含账号、会话、审计或历史版本。导出使用紧凑 JSON 保持大小限制；未保存编辑不包含在导出中。下载的知识内容需妥善保管。

具有读取、编辑权限且无未保存编辑、无待核对状态时可选择 UTF-8 JSON 文件。文件在浏览器本地读取，不上传、不执行内容或访问其中的链接。限制 1 MiB、1000 条，校验未知字段、字段类型、必填、Unicode 字符数、重复 ID、关键词及控制字符；错误指明条目序号和字段。服务器保存时仍执行最终校验。

预览相对当前已读取草稿的新增、修改、删除数量，支持查看全部待导入内容；确认后整份替换本地草稿（不是合并），清除搜索并回到首条。空数组明确提示清空。取消或错误文件不修改草稿；读取中取消、账号变化或草稿变化会丢弃读取结果。确认后仅标记未保存，仍需手动保存与发布，保留版本冲突、空发布确认和权限保护。

## FAQ 批量回归检查

本地 UTF-8 JSON 用例数组，每批 1–50 条、文件最多 128 KiB。每条为 id（唯一、最多 64 字符）、query（1–512 字符）、expected_id（FAQ ID 或显式 null）。指定 ID 出现在前 3 条命中中算通过；null 要求零命中。不是完整结果集合断言，也不验证模型答案。无版本为 unavailable，不算通过或退步；空版本有有效版本号，可按零命中正常判定。退步仅指发布版 pass、草稿 fail。

选择文件只做本地校验，明确点击运行后才提交到 POST /internal/knowledge/batch。接口要求 knowledge.read、管理会话及同源 Origin，请求体不超过 132 KiB；校验全部用例后加载一次仓库快照、编译两个 FAQ 版本各一次，并调用原有 Retrieve。返回 revision、两边版本号、逐条命中 ID/状态/退步标记。无数据库迁移，不保存用例、报告或审计记录，不调用模型，失败不自动重试，不返回部分成功报告。旧 revision 返回 409。

下载 JSON 报告包括原用例、版本号、结果和浏览器生成时间，不含账号或会话。报告不自动允许或阻止发布；修改、保存、核对、退出会清除当前报告。文件和报告请勿填写真实敏感资料，下载后自行保管；部署代理不得记录请求体。
