## 已观察结果

| 流程 | 页面验证 |
| --- | --- |
| 客户咨询 | customer_a 登录后发送虚构问题，出现消息已发送及固定回复 |
| 人工接待 | 申请人工后显示等待接管；staff 登录工作台看见队列，打开历史并明确接管后可发人工回复 |
| 回复保留 | 客户刷新后看见人工回复及人工正在处理状态 |
| 结束会话 | 坐席结束后队列为空；客户刷新显示会话已结束，输入被禁用并提供新咨询入口 |
| 客户切号 | A 退出后 B 登录，显示自己的空会话；点击上一轮记录提示没有上一轮咨询，不显示 A 的消息 |
| 客户重登 | B 退出、A 重新登录，原问题、固定回复、人工回复及关闭状态全部可见 |
| 知识草稿 | 独立管理员登录，从空知识库新增 FAQ，填写 ID/标题/答案/来源/关键词后保存，显示 r1 且尚未发布 |
| 发布前检索 | 草稿命中 browser-hours，当前发布版本提示尚无此版本 |
| 发布确认 | 点击发布展开页面内确认区域，确认执行后 r2，显示当前发布版本及发布操作记录；无原生弹窗阻塞 |
| 发布后检索 | 已保存草稿和当前发布版本均命中虚构 FAQ，内容一致 |
| 管理员重登/刷新 | 退出到登录页，重新登录并刷新后 r2、FAQ 内容及发布版本保持不变 |

本轮未发现阻断上述路径的按钮、确认交互或状态提示问题，无业务代码修改，也没有新增需要处理的优化项。不自动提交、推送或发布新版本。

## 范围与清理

验证的是同一浏览器会话中按退出/登录切换客户，以及客户/坐席/管理三个页面；不是跨浏览器、移动端、并发切号、断网故障或完整无障碍测试。没有执行新咨询按钮、FAQ 文件导入/批量报告、版本回退、未命中采集队列或真实模型链路。本轮没有重启数据库，停机恢复由上轮 HTTP 验收覆盖。

临时服务已停止，所属容器、数据卷和网络经 Compose 项目标签核对后删除；测试配置和密码文件已清理，旧资源未动。页面截图含虚构数据，留在本机临时验收目录，不放入正式源码附件：`/tmp/omni-v120-browser-sV9EVp/` 下的 `customer-human-reply.png`、`customer-relogin-history.png`、`knowledge-published.png`。临时目录可能被系统回收；本文是长期保留的检查摘要。

临时启动器生成的 browser-environment-report.json 只记录环境准备与清理，继承的 browser_tested:false 不能代表本轮页面结果；页面验收以上表实际观察为准，不把环境报告当成 UI 自动测试报告。
