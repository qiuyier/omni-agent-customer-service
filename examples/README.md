# 示例与验证资料

本项目是通用客服底座。电商和 CRMEB 只是接入与测试样例，不定义系统的业务边界。

## 阅读顺序

要接入一个没有客服的业务后端，另见[独立 Node.js 接入样例与接口清单](../integrations/standalone-host/README.md)。

1. 阅读[通用接入契约](../docs/integration-contract.md)，确认身份、会话和交付责任。
2. 查看[接入知识样例](knowledge/README.md)，选择需要的资料格式；所有演示知识都不能直接当作真实业务政策。
3. 查看[回归资料](regression/README.md)，了解测试输入与离线检查。
4. 需要追溯实验结论时，再查看[历史归档](archive/README.md)。

## 目录职责

| 目录 | 内容 | 维护约定 |
| --- | --- | --- |
| knowledge/ | FAQ 格式、跨业务与电商样例、CRMEB 测试快照 | 保持现有 FAQ 路径，避免影响运行配置 |
| regression/ | 开发题、保留题、回复题、事实约束与分类语料 | 修改应审阅标签，不按模型输出反向改答案 |
| archive/ | 历史报告、冻结输入、原始模型输出和实验脚本 | 保留成功和失败；原始证据不改写 |

本次仅整理文件与引用，不修改知识内容、模型配置、实验结论或数据库。历史归档不是当前上线验收证明。
