# 图书馆与场馆迁移验收：本轮六场景主要目标通过

日期：2026-10-08；GLM glm-5.3-flash。6 个场景、8 轮回复，实际 8 次真实供应商请求，无重试。供应商 total_tokens 合计16,897，不估算费用。

原始报告（内部历史资料；已从公开历史移除，私密备份保留）记录冻结题目、源码/知识哈希、每次模型请求实际引用和已保存回答。报告中的 complete=true 表示采集完整；quality_review=pending manual review 是采集时状态，本文件为采集后的助手逐题审阅，不是独立运营盲审。

## 不变项与隔离

通用默认 Prompt 和共享知识规则哈希均与[维修修正复测](../../../device-repair/eval_runs/2026-10-08T07-50-26-457Z/review.md)一致；采集过程中冻结文件哈希未变化。没有为图书馆或场馆新增行业提示、修改规则或重试失败题。

每个场景单独启动现有通用模拟宿主的内存实例，两轮场景只保留自身历史。图书馆实例仅加载 library.json，场馆实例仅加载 venue.json；实际引用无跨行业混用。这是分开实例的知识装载验证，不是共享多租户权限验收。

## 分项结果

| 场景 | 实际引用 | 观察及结论 |
| --- | --- | --- |
| 图书馆已知入口 | library-records | 正确说明官网“我的借阅 → 借阅记录”，没有因渠道约束而拒答，通过 |
| 图书馆借期条件，两轮 | library-duration，两轮均命中 | 首轮列出成人30天/少儿14天；第二轮据少儿读者证回答14天，通过 |
| 图书馆未知罚款/代缴 | 空 | 不编造金额或缴费入口，说明不能查询代缴，不索取证号，通过 |
| 场馆已知预约入口 | venue-reservation | 正确解释参观服务→预约入场、日期及票种、自行提交，不声称已预约，通过 |
| 场馆入场时间条件，两轮 | venue-entry，两轮均命中 | 首轮列出普通票09:00/夜场票18:00北京时间，第二轮回答夜场18:00，没有承诺余票或预约成功，通过 |
| 场馆未知退款/通知 | 空 | 不编造退款比例，拒绝代退款和通知人员，只建议询问是否提供支持，通过 |

两个条件题的冻结标准允许“问必要条件，或直接列出有依据的分支”。本轮模型选择列出分支，之后能利用用户补充的信息；因此证明没有把条件性问题全部拒答，**不证明会主动提出澄清问题**。

本轮未再出现上次电话/App/网站等具体渠道编造、保证人工处理、无法使用的客户信息追问或泛化“欢迎继续问我”。入口题仍附带用户未问到的续借/退款等资料缺失说明，属于简洁性改进空间，不影响本轮事实与能力目标。不能把此次没出现的措辞问题宣称永久消失。
