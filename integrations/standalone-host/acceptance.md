# 独立业务后端接入验收

日期：2026-10-08。本轮新增独立 Node.js 业务后端和测试启动器；Go 入口仅装配既有客服核心、内存仓库与身份网关。没有复制或修改 CRMEB、客服核心、前端源码或构建资源，没有模型或数据库调用。

## 已验证

真实 Node HTTP 后端 + 真实 Go 网关的完整用例通过：

- 后端自己的 member-1001/member-1002 登录身份，服务端交换后得到不同会话。
- 现有首页、聊天页、JS/CSS 原样从公共业务站点提供；私有身份交换与全权限 /v1 路由未代理。
- 未登录、跨源、伪造客户/角色字段、query 指定会话、非演示账号均被拒绝。
- 用户乙的登录 Cookie 搭配用户甲聊天凭证被拒绝。
- 消息保存和固定回复；相同事件重放结果不变，不增加消息。
- 同名事件在两个账号内互不冲突，历史互不串用。
- 刷新重新获取身份复用有效凭证；退出后的旧登录失效；重新登录同账号恢复原内存会话，但不能把旧登录签发的聊天凭证放到新登录使用。
- 原登录中切换账号撤销旧登录，进入新账号的原会话。

另一个本地上游替身用例通过：

- 上游实际收到的 customer_id 为业务后端认证得到的 member-1001；身份交换使用宿主密钥，消息访问使用受限凭证，未混用。
- 历史请求挂起时退出登录，释放上游响应后公共端返回401，不把迟到内容返回浏览器。
- 模拟时钟超过30分钟后，旧登录不能再交换身份。


新网关入口没有单独 Go 单元测试，由第一条 Node HTTP 集成用例实际构建并运行；第二条命令验证编译及已有核心测试，不冒充新增网关测试覆盖。

## 未覆盖与责任

未做真实浏览器视觉/交互验收、真实用户密码/SSO认证、HTTPS上线、数据库重启恢复、付费模型质量、多租户知识授权或压力测试。固定回复只能验证链路。账号选择端点不可上线，真实业务须替换认证与会话存储；生产私有网关不能被浏览器绕过代理直接访问。

退出阻止后续访问和迟到内容回传，不回滚已经到达网关的发送。私有凭证在网关仍可能存活至到期，不能把公共端登录失效描述为全局凭证撤销。

本样例的通用性证据是 Node 业务后端仅实现登录、身份桥接及精确代理，不理解消息领域对象、不直接读数据库或嵌入客服核心；核心与页面复用既有实现。它是可阅读、可运行的接入参考，不是无需开发即可接入任意系统的通用插件。
