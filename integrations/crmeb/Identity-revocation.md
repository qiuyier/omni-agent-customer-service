# 恢复启用不恢复旧客服权限

2026-10-20。本机实现、安装及回归完成。修正此前[身份验收失败](Identity-acceptance.md)，不改写旧报告。

## 实现与适用边界

原缺口：只在请求时读取 status，无法发现旧登录没有请求期间发生的“禁用 → 恢复”。本次使用持久化权限版本，不依赖请求碰巧遇到禁用窗口。

- 新增 MySQL `eb_omni_identity_revision`：realm、subject_id、随机 UUID 格式 revision。api/kefu 分域，版本不是秘密或认证凭据。
- 对 `eb_user`、`eb_store_service` 各安装 INSERT/UPDATE/DELETE 触发器。状态实际变化时轮换版本；客户 is_del 变化也轮换。新增/删除保留或更新版本，避免同主键复用旧权限。触发器与原数据写入处于同一 InnoDB 事务，回滚一同回滚；SQL 直接更新同样覆盖。
- 原 `JwtAuth::getToken` 在签名前增加可选版本声明 `omni_identity_revision`，仅 api/kefu 使用。不接受调用者自报版本。版本读取失败时不写声明，原登录仍可完成，但新客服接口拒绝该凭据。
- 附加控制器先用原解析器验证签名、有效期、登录缓存和角色，再比较签名内版本与当前数据库版本。客户/客服请求前及返回前的现有身份复查都会执行新校验。
- 旧登录缺少声明或版本不一致，只失去 `/api/omni-chat/*` 权限；不删除所有原商城登录缓存，不改密码、原有效期或原客服认证规则。安装后需重新登录才能使用新客服入口。

**这是权限撤销，不是所有业务系统的全局登出功能。** 请求已被网关接受的写入可能仍完成，返回前撤销校验不回滚已提交消息。私有网关必须仍不可被浏览器绕过代理访问。

修改对象：仓库 `IdentityRevision.php`、`OmniChat.php`、单测及迁移工具；本机安装新增 `extend/omni_chat/IdentityRevision.php`，更新附加控制器，并对原 `crmeb/utils/JwtAuth.php` 加 6 行签发钩子。通用 Go 核心、商城密码、原业务表字段未改；未增加退款/订单等业务逻辑。

## 安装、迁移与运行责任

1. 先阅读 [identity_revision_migrate.php](identity_revision_migrate.php)。固定本机 CRMEB 路径；不带 `--apply` 只检查表引擎与对象冲突。目标为其他实例时必须重新核对表名、权限、复制方式和部署窗口。
2. 备份原控制器与签发器；本轮私有备份为 CRMEB `runtime/omni-chat-deploy/revision-backup-fqHiCx/`。安装前没有专用版本表，也没有现有触发器；迁移没有改原表定义或覆盖现有触发器。
3. 显式迁移建立新表与 6 个触发器，先装触发器再补齐已有账号，保留期间变化的新版本。DDL 会自动提交，失败可能留下部分对象；工具拒绝覆盖已有对象，不自动删除后重试。
4. 安装 `IdentityRevision.php`，应用 [签发钩子补丁](identity-signing-hook.patch)，更新附加 `OmniChat.php`；不要把仓库旧版本直接覆盖用户改动。先检查差异，再部署并要求重新登录。
5. 核验版本表/触发器存在、读取主库而非延迟副本；数据库账户要有必需权限。版本表异常会使新客服访问失败关闭；触发器写入失败会使原账号变更事务失败，需纳入数据库监控。

这些机制必须随业务数据库备份恢复。**不能单独恢复旧版本表、删除重建表、或绕过/移除触发器后声称撤销仍有效。** 全库恢复可能恢复旧版本与登录缓存；恢复流程应重新轮换版本或使旧登录失效并验收。本轮不宣称已完成备份恢复演练。

## 安全暂停与回退

优先关闭新客服入口/桥接，保留版本表、触发器和数据，原商城登录仍可按原逻辑工作。不要直接恢复旧控制器继续开放新接口，那会重新引入本次缺口。

如必须卸载，先停止新接口使用、撤销相关访问并评估账号状态变更窗口，再由维护者按备份核对文件差异；本轮未执行卸载或删除 DDL。备份是回退材料，不是已验收的自动回退程序。

## 通用性

其他宿主不需要 CRMEB 表或 MySQL 触发器；它们应提供同样的语义：权威状态变化原子推进不可回退的权限版本，登录携带可信版本，客服访问每次验证版本。可使用宿主已有 session_version、撤销事件或账号级会话撤销机制。不能只轮询当前 status 或只删除正在请求的单个登录。

阅读顺序：本文 → `IdentityRevision.php` → `OmniChat.php` 与签发钩子 → 迁移工具 → 单测与原始验收报告。归档真实测试脚本固定本机目标，会临时修改测试账号状态，不能直接用于其他环境。
